# Sorman - Personal Finance Management System

Sorman App is a full-stack personal finance management application built to demonstrate practical software engineering skills using Java and Spring Boot.

The application allows users to securely manage income and expenses, track spending habits, organize transactions by category, and view financial insights through an interactive dashboard.

## Live Demo

🔗 **Live Application:** <a href="https://sorman-budgetapp1.onrender.com" target="_blank">[Open Sorman-App](https://sorman-budgetapp1.onrender.com)</a>

## Technical Stack

### Backend

* Java 17
* Spring Boot 3
* Spring Security
* JWT Authentication
* Spring Data JPA
* Hibernate
* PostgreSQL (NeonDB)
* Maven

### Frontend

* React
* Tailwind CSS
* Recharts
* Axios

### Deployment

* Render
* Neon PostgreSQL

## Key Features

* User Registration & Login
* JWT-based Authentication & Authorization
* Income and Expense Management
* Transaction Filtering and Search
* Budget Tracking
* Financial Dashboard & Analytics
* Responsive User Interface

## Running Locally

### Backend

```bash
cd backend-java
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```
